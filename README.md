## 数据集介绍

### 刺激

实验中的听觉故事来源于16个故事，分别由一名男性和一名女行讲述。通过一对插入式耳机，以适当音量呈现给每位受试者。

### 脑电数据采集

- 32导联 AgCl 电极帽
- 1000Hz采样率

### 实验流程

- 将受试者分为2组，各有10名受试者，分别标记为1组和2组。1组进行接收音频作为唯一刺激(audio-only)的实验，2组进行接收音视频(
  audio-video)作为刺激的实验。
- 两组的受试者成员没有重合，确保刺激故事对受试者完全陌生。

1. 音频刺激(audio-only)：在仅有音频作为刺激的采集实验过程中，, 受试者只需佩戴耳机, 根据指令确定注意力方向,
   即受试者需集中注意力关注空间方向上左耳/右耳的故事。
2. 音视频刺激(audio-video)：根据每次试验播放的视频中讲述者的性别确定注意力方向, 要求受试者的视线一直注视讲述者的唇部变化,
   以更好地集中注意力。

- 每名受试者都进行了16次试验，每次试验持续152s，其中包括开始之前2s的静音时间。 
- 试验中设置了休息时间。 
- 在整个实验期间, 目标音频的空间位置及说话者的性别都是随机呈现的。

### EEG数据预处理

1. 应用陷波滤波器消除50Hz处的工频干扰
2. 使用有限长单位冲激响应(FIR)滤波器，进行高通和低通滤波，以去除电压漂移和高频噪音
3. 降采样到128Hz
4. 独立成分分析(ICA)处理数据
